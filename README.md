# 赛道地图与圈速模拟

公开静态网站，访问者无需登录。包含浙江、株洲与纽北地图、车辆参数、二维模拟、GPS 虚拟座舱及 CSV/JSON 导出。

运行入口为 index.html，全部计算在浏览器中进行。临时车辆参数不会跨设备自动同步，可导出留存。模型尚未校准，不代表实测圈速或已验证的最快线路。

站点包含已授权公开的实测派生地图和分析页面；公开地图来源及许可保留在各页面。


2026-10-19：车辆模拟新增固定道路内的走线优化、连续弯与出弯方案比较、可调假设路宽/车宽/边缘余量，以及同步局部走线图。优化线和尺寸假设随 CSV/JSON 导出；实测 GPS 回放保持独立。当前结果仍为未实车校准的二维演示。

2026-10-20：新增可调弯内压路肩上限（默认 0.30 m，0–0.50 m），保留直道和弯外侧余量；支持定位压肩位置、车宽截面显示及导出设置。路肩位置与宽度为假设，未模拟高度和抓地差异。
